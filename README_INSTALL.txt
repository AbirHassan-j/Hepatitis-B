LIVERQUEST — INSIDE THE INFECTION
================================
A three-page website with a rebuilt, interactive, full-width HBV adventure game.

INSTALLATION ON GITHUB PAGES
1. Download the ZIP and extract it on your computer.
2. Back up your existing GitHub repository first (Code > Download ZIP).
3. Upload the eight website files from this ZIP to the ROOT of your GitHub repository:
   index.html, cells.html, invasion.html, credits.html,
   site.js, style.css, adventure.js, adventure.css
4. KEEP your original cell-city-Video1.mp4 file in the same root folder.
5. Commit the changes. GitHub Pages usually updates shortly afterward.
6. Force refresh your browser with Ctrl+Shift+R.
7. Only AFTER testing, delete microscope.html, lab.html, finale.html if desired.

WHAT WAS CHANGED
- Original restored Mission Control and Cell City logic is preserved in site.js.
- Navigation and homepage mission cards now link to three pages.
- invasion.html uses its own dedicated adventure.js and adventure.css.
- There is NO science-files sidebar; the game has story dialogue, visual
  investigation checkpoints, a virus production visualization, tissue scanning,
  and a prevention mission with active illustrated feedback.
- No standalone multiple-choice quizzes.

NOTE ABOUT SCIENCE
The talking virus/character is an educational game fiction. HBV does not
literally have a face or chase people inside cells. The infection pathway
uses scientifically grounded descriptions of attachment/entry, transport,
cccDNA, viral reproduction, immune-response-mediated injury, and prevention.
